# SaLWER---SaLAI's WER Calculation Toolkit

## Introduction

SaLWER is a comprehensive toolkit for calculating Word Error Rate (WER) at both the segment and word levels, with illustrations focusing on semantic segmentation for Air Traffic Control (ATC) communications.

### The Necessity of WER for Semantic Segments

Traditional WER evaluates transcription quality at the utterance level, treating all errors equally regardless of their semantic importance. However, not all words carry equal weight in real-world applications. For example, in Air Traffic Control (ATC) communications, a misrecognition of a critical command word is far more consequential than a misrecognition of a filler word.

SaLWER addresses this by first segmenting reference transcripts into semantic segments based on functional categories. These segments represent semantically meaningful units (e.g., commands, information elements). We then calculate WER for each segment, providing a more nuanced evaluation that reveals whether the ASR system is failing on the most critical parts of the communication. This is especially valuable for safety-critical applications where you need to know not just the overall WER, but the WER specifically on key semantic segments.

### The Necessity of WER for Every Word

Beyond segment-level analysis, word-level WER provides insights into the performance of the ASR system on individual words. This fine-grained analysis helps identify specific words that are systematically misrecognized—whether due to insufficient training data, rare vocabulary, or acoustic challenges.

Word-level WER can be used to evaluate whether specific words have been trained or fine-tuned enough times to achieve reliable recognition. This is crucial for targeted data collection and model improvement. For instance, if a particular callsign or technical term consistently shows a high WER, that word can be prioritized for additional training.

Unlike segment-level WER, which requires prior semantic segmentation, word-level WER requires no additional labeling. The calculation works directly from the alignment between the reference and inference transcripts. Words that appear in the reference are tracked and their individual error patterns are computed.

### Format of Transcripts

SaLWER focuses on evaluating transcriptions of long audio files, such as ATC communication recordings. The reference and inference transcripts are stored in VTT or SRT format, which are common subtitle formats that support time-aligned cues.

In our examples, we use ATC communication transcriptions, where each cue represents a single transmission from either a controller or a pilot. These transcripts are organized into separate folders:

-   `reference/`: Contains the ground truth transcripts.
-   `inference/`: Contains the transcripts generated by the ASR system.

Each cue in the VTT/SRT file is aligned by index, allowing SaLWER to compare the reference and inference cue-by-cue.

## Functional Classification and Semantic Segmentation of ATC Cues

SaLWER supports semantic segmentation of ATC transmissions in the reference files using a two-step process:

### Functional Classification

Each transmission is classified into a functional category based on its role in the communication. These categories include command types (e.g., DESCEND, CLIMB, HEADING), information elements (e.g., QNH, wind), and other communication functions. The classification is performed using a Large Language Model (LLM) following the taxonomy defined in our DASC paper.

### Semantic Segmentation

Once classified, each transmission is further segmented into semantic segments.

For detailed methodology, please refer to our DASC paper [ref2].

## Technical Contents

### Principle of Segment- and Word-Level WER Calculation

The core algorithm for segment- and word-level WER is described in ref1 (new paper to be published). The principle extends traditional WER by:

Segmenting the reference transcript into semantic units.

Computing WER for each segment independently.

Aggregating segment-level WER to produce overall metrics.

Tracking individual word errors across the entire corpus.

The application of segment-level WER to ATC communications is detailed in ref2 (DASC paper). This paper demonstrates how semantic segmentation of ATC cues enables more meaningful evaluation of ASR performance in safety-critical domains.

## Running Examples

### Functional Classification and Semantic Segmentation of Cues

The salwer csc command performs both functional classification and semantic segmentation of cues.

#### Directory Version (Processing Multiple Files):

```sh
salwer csc atc0json atc0cns --dir
```

#### File Version (Processing a Single File):

```
salwer csc atc0.json atc0.cns
```

Note:

You must run these commands from the parent folder of the JSON files.

You need to set up your LLM API key (e.g., OPENAI_API_KEY environment variable) to use the LLM-based classification and segmentation.

The current version expects input transcripts in JSON format. VTT format support will be added in a future release.

The output is saved in the CNS (Classification and Segmentation) format.

### Check the Classification and Segmentation Results of LLM

After classification and segmentation, you can check the consistency of the results:

```sh
salwer ccs atc0cns
```

This checking function is similar to parity checking in serial communication. It verifies that:

The total number of words in the reference matches across different representations.

The segmentation boundaries are consistent.

Cues that have mismatches in total word count or WER word count will be printed for manual review.

Important: This check does not guarantee semantic correctness---it only provides an additional layer of validation to catch obvious inconsistencies. Always visually inspect critical segments.

### Calculate the Average WER

Calculate the overall WER across all cues:

```sh
salwer wer average --ref <reference_folder> --hyp <hypothesis_folder>
```

This computes the standard average WER, including:

Average WER across all cues based on the total number of substitutions, insertions, and deletions.

### Calculate the Segmented WER

Calculate WER for each semantic segment:

```sh
salwer wer segment --ref <reference_folder> --hyp <hypothesis_folder> --cns <cns_folder>
```

This computes WER for each semantic segment type (e.g., commands, callsigns, information elements), providing per-segment error rates and aggregated statistics. This reveals which types of segments are most challenging for the ASR system.

### Calculate the Word-Level WER

Calculate WER for every word individually:

```sh
salwer wer word --ref <reference_folder> --hyp <hypothesis_folder>
```

This computes the error rate for each word in the vocabulary, including:

Number of occurrences in the reference.

Number of errors (substitutions, deletions, insertions).

Word error rate (errors / total occurrences).

Percentage of all errors attributed to each word.

This analysis helps identify problematic words that can be targeted for additional training or fine-tuning.
