# Contributing Guidelines

Thank you for your interest in contributing to this project!

## No Direct Pushes

**This repository does not accept direct pushes to the `main` branch.** All changes must be submitted through a **Pull Request** (PR).

If you have write access, you must still create a feature branch and open a PR. The `main` branch is protected.

## How to Contribute

The recommended workflow is to **fork** the repository:

1. **Fork** this repository to your own GitHub account.
2. **Clone** your fork locally: `git clone https://github.com/eraus/salwer.git`
3. **Create a new branch** for your changes: `git checkout -b feat/your-feature-name`
4. **Make your changes** and test them.
5. **Commit** your changes with a clear message. (See *Commit Style* below).
6. **Push** to your fork: `git push origin feat/your-feature-name`
7. **Open a Pull Request** from your fork's branch to this repository's `main` branch.

## Pull Request Checklist

Before submitting a PR, please ensure:

- [ ] Your code builds and runs successfully.
- [ ] You have tested your changes locally.
- [ ] Your branch is up-to-date with the `main` branch.
- [ ] The PR description explains **what** changed and **why**.

## Commit Style

Please write clear, concise commit messages. A good format is:

`type: short description`

Examples:
- `feat: add segment-level GLD calculation`
- `fix: correct typo in README`
- `docs: update installation instructions`

## Reporting Bugs

If you find a bug, please open an **Issue** and include:

- A clear description of the problem.
- Steps to reproduce it.
- Your environment (OS, version, etc.).
- Expected vs. actual behavior.

## Suggesting Features

Feature requests are welcome. Please open an Issue describing the feature, why it would be useful, and any alternatives you've considered.

## Code of Conduct

By participating in this project, you agree to abide by the [Contributor Covenant Code of Conduct](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Please be respectful and constructive.

## Questions?

If you have questions, feel free to open an Issue and tag the maintainers.
